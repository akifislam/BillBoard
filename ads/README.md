Banner images go here.

- 1200 x 300 px (4:1 ratio), WebP preferred (PNG/JPG also fine)
- Keep under ~150 KB; the app refuses anything above 4 MB
- Use a NEW filename for a new banner instead of overwriting — devices cache
  images by URL, so a reused name can serve the old picture for a while
- Keep important text away from the far left/right edges; the banner is inset
  slightly from the screen edges

Reference an image from config.json as:

    https://akifislam.github.io/BillBoard/ads/<filename>
